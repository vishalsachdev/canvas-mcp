i.e. since cutoff)

- **What it does:** `get_my_submission_status` currently marks an assignment OVERDUE purely from
  `due_at < now` with no submission, ignoring Canvas's own `submission.missing` flag. That's a
  real bug — confirmed by reading `src/canvas_mcp/tools/student_tools.py:282-301` directly: the
  `else` branch at line 292 computes overdue/not-submitted from `due_at` alone and never looks at
  `submission.get("missing")` anywhere in the function. The PR replaces that date-comparison
  branch with a direct check on `submission.get("missing")`, so `on_paper`/`none`-type assignments
  (paper exams, participation-only items) that are graded or simply don't take an online
  submission stop being misreported as overdue.
- **Evidence quality:** unusually good for a first PR — measured against the author's own live
  Canvas account (14 courses, 90 assignments): 10 false OVERDUE reports before the fix, all
  `on_paper`/`none` type, 1 true positive Canvas actually flags `missing`. Includes a regression
  test (`test_get_my_submission_status_trusts_canvas_missing_flag`) built from that finding, plus
  an update to the existing overdue fixture to include the `missing` key. Diff is small and
  targeted: `student_tools.py` (+5/-10) and the test file (+37/-1).
