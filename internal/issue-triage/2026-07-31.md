### #198 — [Bug]: file upload without a folder creates a spurious "unfiled" parent folder

**Likely root cause, fairly confident** — `tools/files.py:312-315`:
```python
if folder_path:
    upload_request_params["parent_folder_path"] = folder_path
```
When `folder_path` is `None`, **no folder parameter is sent to Canvas at all** in the `POST /courses/:id/files` request. Canvas's own default behavior when no parent folder is specified is to place the file in "unfiled," not the course files root — so the docstring's claimed default doesn't match what actually happens when the parameter is simply omitted. This is a straightforward reproduction, not a guess, but I haven't run it against a live instance to confirm Canvas's exact default-folder behavior matches this reading of the code.

**Suggested fix (unverified, not applied):** explicitly send `parent_folder_path: "/"` when `folder_path` is `None`, rather than omitting the key.
